# FRIENDSHIP: DIGITAL ARCHIVE  
### Version 1.0 | Release Date: 2026

---

## 1. ABOUT THE PROJECT

This website is a private non‑commercial project created to preserve and visualise memories of the first year of friendship between two people.  
It is not a public platform, does not collect personal data, and does not use third‑party analytics services.

**Target audience:** one person (the recipient).  
**Purpose:** to convey warm emotions and capture important moments in an interactive form.

---

## 2. FEATURES

| Module          | Description                                                                 |
|-----------------|-----------------------------------------------------------------------------|
| Gallery         | Displays photos in a grid. Clicking on a photo opens a full‑screen view (Lightbox). |
| Stories         | Text blocks with memories, marked with dates.                               |
| Quotes          | A block with wishes and quotes, presented as cards.                         |
| Responsiveness  | The site displays correctly on devices with screen widths from 320 px.      |

### 3.2. Navigation
- Scrolling the page allows you to sequentially browse all sections.
- To enlarge a photo – click on any card in the gallery.
- To close the enlarged photo, click the cross in the upper‑right corner, press the `Esc` key, or click on the darkened background.
